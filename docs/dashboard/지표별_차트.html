슬라이드 05 · 가설 2 검증

낮은 예약률의 원인은 페이지인가, 유입인가

가설 2 — 낮은 예약 CTA율(1.11%)의 원인은 랜딩페이지나 버튼이 아니다. 진짜 원인은 유입되는 사용자의 예약 의도가 낮다는 데 있다.
직접 증거가 없으므로 소거법으로 검증합니다. 페이지 쪽 용의자를 하나씩 지우고, 남는 것을 지목합니다.
