이 대시보드 사용법

운영 모니터링용이다. 화면은 위에서 아래로 네 덩어리다.
  1. ① KPI 5장 — 현황 확인. 카드를 클릭하면 그 지표가 아래 드릴다운의 기준이 된다(빨간 테두리).
  2. ② 왼쪽 행동 퍼널 — 도착 → 클릭 → 행동 → CTA → 예약 유도. 단계를 클릭하면 그 집단으로 화면 전체가 좁혀진다.
  3. ③ 오른쪽 드릴다운 — 광고세트 › 소재 › 세그먼트. 행을 클릭하면 한 단계 펼쳐진다.
  4. ④ 히트맵·CTA·메뉴 — 셀·행을 클릭하면 그 조건이 전체에 걸린다.
조작법
  1. 같은 곳을 다시 클릭하면 해제된다. 상단 필터 칩으로 개별 해제도 가능하다.
  2. 차트 오른쪽 위 ⓘ는 읽는 법과 해석 시 유의점이다.
주의 — 유도당 비용은 지출을 일별로 갖고 있어 어떤 기간에서도 나온다. 도착률만은 분모인 고유 링크클릭을 기간별로 쪼갤 수 없어 전체 기간에서만 나온다. 그리고 시간대·행동단계·세그먼트·CTA·메뉴로 좁히면 둘 다 비활성(—)이 된다 — Meta 지출을 "토요일 20시"나 "mobile 사용자"로 나눌 방법이 없기 때문이다.
색 — ■ 빨강 = 선택·이탈, ■ 차콜 = 정상·기준, ■ 회색 = 표본 부족(방문 300 미만).

· 관측 기간 하노이 2026-07-20 ~ 08-02 (14일). 7/20은 광고가 하노이 13시경 시작된 부분일(약 11시간)이라 "최종일 vs 전일" 비교의 기준선에서는 제외한다. 8/3은 04:13 중단된 부분일이라 분석에서 제외했다.
· 7/29에 소재를 교체했다 — 1차 7/20~28(9일) · 2차 7/29~8/2(5일). 드릴다운의 1차만·2차만 태그가 해당 차수에서만 집행된 소재다 (1차만: 가족×생일 이미지·비즈니스×공간 캐러셀 / 2차만: 가족×생일 영상·비즈니스×공간 영상). 기간 필터를 걸지 않으면 두 차수가 합산되므로, 소재를 서로 비교할 때는 집행 기간이 다르다는 점을 감안할 것.
· 노출·링크클릭·지출은 소재별 × 일별로 확보돼 있어 기간을 어떻게 잘라도 합산된다 (유도당 비용·CTR·CPC가 모든 기간에서 나온다). 다만 고유 링크클릭은 Meta가 조회 기간마다 따로 중복 제거하므로 쪼갤 수 없다 — 도착률은 전체 기간에서만 산출되고 기간 필터 중에는 —가 된다.
· 일별 실적은 지면 분류 리포트에서 집계했다. 노출위치가 귀속되지 않은 소수 노출이 빠져 노출 460,136 · 링크클릭 17,825로 계정 합계(460,195 · 17,828)보다 각각 59·3 적다(0.02%). 지출은 완전 일치한다.
· 방문자 = 고유 device_id (Page Viewed 또는 session_start 발생). 로그인이 없어 사람이 아니라 기기 단위이며, Amplitude UI에서 Page Viewed · 고유 사용자로 조회하면 8,083으로 1명 차이가 난다.
· 고유 사용자 지표는 행의 합 ≠ 전체다. 소재별 방문자 합 8,217 vs 전체 8,084(중복 133명), 소재별 Meta 고유클릭 합 15,124 vs 전체 14,570(중복 554명). 세로 합계로 검산하지 말 것.
· 소재·광고세트 귀속은 세션 단위(세션의 첫 도착 이벤트 기준)다. 한 세션 안에서 다른 소재의 광고를 다시 클릭한 경우가 7건 있어, 이벤트 단위로 집계한 원본 시트보다 소재별 방문자가 최대 2명 적다 (예: business_taste 4,413 vs 시트 4,415 · 전체 8,211 vs 8,217). 필터가 걸리는 대시보드에서는 세션 단위 귀속이 맞아 이쪽을 채택했고, 유도율 등 비율은 표시 자릿수에서 동일하다.
· 도착률 = 방문자 ÷ Meta 고유 링크클릭(사람 : 사람). CTR 3.87%·CPC ₫495는 전체 링크클릭 17,828 기준으로 분모가 다르다 — 목적이 다르기 때문이다(Meta 과금 단위 vs 사람 이행률).
· 유도당 비용 = 지출 ÷ 예약 유도 사용자. 클릭수는 계산에 들어가지 않는다.
· 측정 한계 — POS 미연동으로 실제 예약 완결은 측정 불가('예약 유도'가 상한선) · 스크롤 뎁스 미계측으로 이탈 지점 확인 불가 · session_end가 14.9%에만 있어 체류시간 측정 포기 · 메뉴 관심도 표본 37명 · Dead Click 89건 중 34건이 로고 오탐.
